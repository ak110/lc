# スケジューラー

指定した日時条件に基づいてタスクを自動実行する機能である。

## スケジューラーアイテム

スケジューラーの設定単位は「アイテム」である。各アイテムには以下を設定する。

- 名前 — アイテムの識別名
- スケジュール — いつ実行するか（複数設定できる）
- タスク — 何を実行するか（複数設定できる）
- タスク間隔 — 複数タスクを順次実行する際の待機時間（ミリ秒）

## スケジュール条件

各スケジュールには時刻条件と日付条件を組み合わせて設定する。

### 時刻条件

| 種類     | 説明                                                              |
| -------- | ----------------------------------------------------------------- |
| 指定時刻 | 特定の時刻 (例: 9:00、14:30、18:45) に実行                        |
| 間隔     | 指定した時間範囲内でN分ごとに実行 (例: 9:00～18:00の間、60分ごと) |

### 日付条件

| 種類     | 説明                                                  |
| -------- | ----------------------------------------------------- |
| 曜日     | 期間内の特定の曜日に実行 (例: 1/1～12/31の月・水・金) |
| 日数間隔 | 期間内でN日ごとに実行 (例: 1/1～12/31の間、7日ごと)   |

## タスク設定

各タスクには以下を設定する。

| 項目         | 説明                                                     |
| ------------ | -------------------------------------------------------- |
| ファイル名   | 実行するファイルのパス                                   |
| パラメーター | コマンドライン引数                                       |
| 表示         | ウィンドウの表示方法（通常・最小化・最大化・非表示など） |
| 優先度       | プロセスの優先度（高・通常・低など）                     |

## 実行中の予定の扱い

同じアイテムは同時に1つだけ実行する。
アイテムの実行は、タスクを上から順に実行し、タスク間隔の待機も終えた時点で完了とする。
らんちゃが待つのはメッセージ表示タスクを閉じるまでであり、起動したアプリの終了は待たない。

- 実行中に同じアイテムの予定時刻に達した場合は、何回達しても1回分の保留にまとめ、実行の完了後に1回だけ実行する
- 別のアイテムは、名前が同じでも待たずに実行する
- 実行中にアイテムを編集しても、実行中のタスクは開始時の設定のまま続く。保留分は編集後の設定で実行する
- 実行中にアイテムを無効化・削除した場合は、保留分を破棄する
- 一時停止中は保留分に着手しない。再開すると、有効なアイテムの保留分を1回実行する
- 終了処理が始まった後は、保留分を破棄する

アイテムの複製は別のアイテムとして扱い、元のアイテムの実行を待たない。

## テスト実行

アイテムの編集画面で「テスト実行」ボタンを使うと、スケジュール条件を待たずにタスクを即座に実行して動作を確認できる。
テスト実行はスケジュールによる実行とは独立しており、同じアイテムをスケジュールで実行中でもすぐに実行する。
