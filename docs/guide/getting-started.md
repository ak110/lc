# はじめに

## インストール

[Releases](https://github.com/ak110/lc/releases)からZIPをダウンロードし、任意のフォルダに展開する。
`らんちゃ.exe` を起動するとタスクトレイに常駐し、設定したホットキーでランチャーを開ける。

## 初回セットアップ

1. `らんちゃ.exe`を起動する
2. タスクトレイアイコンを右クリックして「設定」を開き、ホットキーを設定する
   - メモパッドを使う場合は「メモパッドのホットキー」も割り当てる（初期状態は未割り当て）
3. コマンド型ランチャーで未登録のコマンド名を入力し、「追加」からリンク先などを設定する
4. 設定画面の「ショートカット」にある「送るに登録」を押すと、エクスプローラーの「送る」→「らんちゃに登録」からファイルを登録できる

`らんちゃ.exe <ファイル>`でもコマンドを登録できる。
登録後の編集は[コマンド型ランチャー](./command-launcher.md)を参照。
ボタンへファイルをドロップする登録方法は[ボタン型ランチャー](./button-launcher.md)を参照。
ホットキー以外の設定と常駐中の操作は[設定・タスクトレイ・通信](./settings.md)を参照。

## コマンドライン引数

| 引数       | 動作                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| `/close`   | 既に常駐している場合、終了する                                                     |
| `/restart` | 既に常駐している場合、再起動する                                                   |
| それ以外   | 実在するファイルまたはフォルダーならコマンドの登録画面を開く。それ以外は登録しない |

## 保存ファイルとバックアップ

設定やコマンドは`らんちゃ.exe`と同じフォルダーへ保存する。

| ファイル            | 内容                                                       |
| ------------------- | ---------------------------------------------------------- |
| `らんちゃ.cfg`      | 設定                                                       |
| `らんちゃ.cmd.cfg`  | コマンド一覧                                               |
| `らんちゃ.btns.cfg` | ボタン型ランチャーの配置                                   |
| `らんちゃ.sch.cfg`  | スケジューラー設定                                         |
| `らんちゃ.memo.cfg` | メモパッドの内容                                           |
| `らんちゃ.dat`      | 常駐中のウィンドウの識別情報とスケジューラーの最終確認時刻 |
| `logs/`             | 診断ログ                                                   |
| `favicons/`         | Webサイトのアイコンのキャッシュ                            |

5種類の`.cfg`ファイルを正常に読み込めたときと保存するときに、直前の正常な内容を`<ファイル名>.bak`（例: `らんちゃ.cmd.cfg.bak`）へ1世代だけ残す。
`.dat`、診断ログ、アイコンのキャッシュは、このバックアップと読込失敗時の保存停止の対象に含めない。

### 読み込めないファイルがある場合

起動時や再読込時にファイルを読み込めないと、ファイルごとに通知を表示する。
そのファイルへの保存は止まり、読み込めなかった内容を空のデータで上書きすることはない。

- バックアップがある場合は、通知で「はい」を選ぶとバックアップの内容へ戻す。
  読み込めなかったファイルは`<ファイル名>.broken-<日時>`という名前で残し、復元後は保存も再開する
- 「いいえ」を選んだ場合とバックアップが無い場合は、そのファイルを空のデータで表示したまま保存しない。
  ファイルを直すか`.bak`を元の名前へコピーしてから、らんちゃを再起動する

コマンド一覧を読み込めない間は、「送る」メニューからのコマンド登録も行わない。
初回起動のようにファイルもバックアップも無い場合は、初期状態で始める。

## 更新に失敗した場合

ネットワーク更新は、らんちゃを終了してから配布ファイルを1つずつ置き換える。
設定・コマンド・メモなどの保存ファイルは置き換えの対象外である。

- ダウンロードや展開の段階で失敗した場合は、その場でエラーを表示する。インストール済みのアプリは変更しない
- 置き換えの途中で失敗した場合は、置き換えたファイルを更新前の版へ戻してから、更新前のらんちゃを起動し、失敗を通知する
- 更新前の版へ戻すことにも失敗した場合は、更新前のファイルを残した退避フォルダー（`_update_backup_<番号>`）の場所を通知する。
  らんちゃが起動していないことを確かめてから、退避フォルダーの中身をすべてらんちゃのフォルダーへ上書きコピーすると元に戻る
