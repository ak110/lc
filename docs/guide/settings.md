# 設定・タスクトレイ・通信

タスクトレイアイコンを右クリックすると、設定や各機能を開くメニューを表示する。

## 設定画面

タスクトレイの「設定」、またはコマンド型ランチャーの入力を消去してから「設定」を選ぶ。
項目を変更した後は「OK」で保存する。

| 項目                           | 動作                                                                                    |
| ------------------------------ | --------------------------------------------------------------------------------------- |
| ホットキー                     | Ctrl・Alt・Shift・Winとキーを組み合わせ、コマンド型ランチャーの表示・非表示を切り替える |
| トレイアイコンを表示する       | タスクトレイでのアイコンの表示を切り替える                                              |
| トレイアイコンのダブルクリック | コマンド型ランチャーの表示、または設定画面を開く操作を選ぶ                              |
| コマンドリストのダブルクリック | コマンドの実行・フォルダを開く・設定・削除から選ぶ                                      |
| 起動時にウィンドウを表示しない | コマンド型ランチャーを隠した状態で常駐を始める                                          |
| 大きいアイコンを表示する       | コマンド一覧のアイコンを大きくする                                                      |
| 常に手前に表示する             | コマンド型ランチャーを他のウィンドウより手前に表示する                                  |
| 非アクティブになったら隠す     | 他のウィンドウへ移ったときにコマンド型ランチャーを隠す                                  |
| リサイズを禁止する             | コマンド型ランチャーのサイズ変更を禁止する                                              |
| 実行後隠す                     | コマンド実行後にコマンド型ランチャーを隠す                                              |
| ×ボタン                        | 無効にする・ウィンドウを隠す・らんちゃを終了する、のいずれかを選ぶ                      |
| 置換環境変数の設定             | パスの保存に使う環境変数を選ぶ（後述）                                                  |
| ショートカット                 | スタートアップと「送る」へ登録する（後述）                                              |
| ボタンランチャーの起動方法     | 無効・左ボタンを押しながら右クリック・右ボタンを押しながら左クリックから選ぶ            |
| 列数・行数                     | ボタン型ランチャーのグリッドの大きさを指定する                                          |
| メモパッドのホットキー         | メモパッドの表示・非表示を切り替えるキーを指定する（空欄で割り当てを解除）              |

## 置換環境変数

環境変数はフォルダなどの値を名前で参照するWindowsの仕組みである。
「置換環境変数の設定」では、使用する変数を追加・削除する。
追加候補には、値が実在するファイルやフォルダを指す変数を表示する。

選んだ変数の値で始まるパスは、`%変数名%`を使った形に置き換える。
たとえば`USERPROFILE`を選ぶと、そのフォルダ内のパスを`%USERPROFILE%\Documents`のように保存できる。
対象はコマンドのリンク先・作業フォルダと、スケジューラーのファイル名である。
置換するのは、環境変数を展開した先のファイルやフォルダが実在する場合に限る。
Windowsから環境変数の変更通知を受けると値を読み直し、以降の起動へ反映する。

## ショートカットの登録

設定画面の「ショートカット」には、次の登録ボタンと対応する「削除」ボタンがある。

| ボタン                     | 登録先と用途                                                            |
| -------------------------- | ----------------------------------------------------------------------- |
| スタートアップに登録       | 現在のWindowsアカウントでサインインしたときにらんちゃを起動する         |
| 共有のスタートアップに登録 | すべてのWindowsアカウント向けに登録する（登録先への書き込み権限が必要） |
| 送るに登録                 | エクスプローラーの「送る」へ「らんちゃに登録」を追加する                |

スタートアップは現在のアカウント用と共有用のどちらかへ登録する。
「削除」は対応するショートカットを取り除く。

## タスクトレイのメニュー

| 項目                             | 動作                                               |
| -------------------------------- | -------------------------------------------------- |
| 設定                             | ホットキーや表示などを変更する                     |
| コマンドの管理                   | 登録済みコマンドを一覧で編集・削除する             |
| スケジューラー設定               | アイテム・スケジュール条件・タスクを編集する       |
| スケジューラー一時停止           | 予定の実行を一時停止し、再度選ぶと再開する         |
| メインウィンドウを表示/非表示    | コマンド型ランチャーの表示を切り替える             |
| メモパッド                       | メモパッドの表示を切り替える                       |
| 実行ファイルのあるフォルダを開く | らんちゃを配置したフォルダを開く                   |
| ネットワーク更新                 | 公開されている版を確認し、更新を実行する画面を開く |
| ホームページを開く               | ドキュメントサイトをブラウザーで開く               |
| 再起動                           | らんちゃを終了して起動し直す                       |
| 終了                             | らんちゃの常駐を終了する                           |

一時停止中の予定の扱いは[スケジューラー](./scheduler.md#実行中の予定の扱い)を参照。
更新に失敗した場合の復旧方法は[はじめに](./getting-started.md#更新に失敗した場合)を参照。

## 外部への通信

### Webサイトのアイコン

リンク先が`http://`または`https://`で始まるコマンドやボタンは、アイコンの取得時にGoogleのファビコン取得APIへ接続する。
送信する登録先の情報はホスト名で、URLのパスやクエリは含めない。
取得した画像は`favicons/`へ保存し、同じホストのキャッシュがある場合は再利用する。

### ネットワーク更新

タスクトレイの「ネットワーク更新」を選ぶと、GitHub Pages上の`https://ak110.github.io/lc/version.json`から版情報を取得する。
更新すると、その情報が示す配布ZIPをダウンロードする。
起動時の自動更新確認は行わない。
