# コマンド型ランチャー

コマンドの一覧を表示し、入力に応じてフィルタリングして実行するランチャーである。

## 主な機能

- コマンドの一覧を表示する
- 入力に応じて先頭一致・部分一致で表示コマンドをフィルタリングする
- 先頭一致時に入力を補完する
- 常駐してホットキーにより起動する

## 操作方法

| キー          | 動作                                                               |
| ------------- | ------------------------------------------------------------------ |
| `Enter`       | 入力欄の右側のボタンと同じ動作（設定・追加・実行）                 |
| `Esc`         | その右のボタンと同じ動作（隠す・消去）                             |
| `Ctrl+Enter`  | 実行できるコマンドがある状態で、そのコマンドの設定ダイアログを開く |
| `Shift+Enter` | そのコマンドのリンク先のフォルダを開く                             |

入力欄の右側のボタンは、入力が空のときは「設定」、該当するコマンドが無いときは「追加」、コマンドがあるときは「実行」と表示する。
一覧へフォーカスを移すと、選択したコマンドが実行対象になる。
`Ctrl`を押すと編集用の「コマンド」、`Shift`を押すと「フォルダ」に切り替わる。
右端のボタンは入力が空なら「隠す」、入力があれば「消去」と表示する。

## コマンドの登録

次のいずれかの方法で登録する。

- 未登録のコマンド名を入力し、「追加」からコマンドの編集画面を開く
- エクスプローラーでファイルを右クリックし、「送る」→「らんちゃに登録」を選ぶ
- `らんちゃ.exe <ファイル>`の形でファイルを引数にして起動する

「送る」の項目は、設定画面の「送るに登録」から作成する。
登録と削除の操作は[ショートカットの登録](./settings.md#ショートカットの登録)を参照。

## コマンドの編集と管理

実行対象のコマンドに対して`Ctrl+Enter`を押すと、コマンドの編集画面を開く。

| 項目             | 設定する内容                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------- |
| コマンド名       | 入力して呼び出す名前                                                                                 |
| リンク先         | 開くファイル・フォルダ・URL                                                                          |
| パラメータ       | 起動時に渡す引数                                                                                     |
| 作業フォルダ     | 起動時に使うフォルダ（省略時はリンク先のファイルがあるフォルダ、リンク先がフォルダならそのフォルダ） |
| 表示             | 通常・最小化・最大化・非アクティブ・最小化非アクティブ・非表示                                       |
| 優先度           | 最高・高・通常以上・通常・通常以下・低                                                               |
| 管理者権限で実行 | 起動時に管理者権限を要求する                                                                         |

タスクトレイの「コマンドの管理」では、コマンド名・リンク先・パラメータ・作業フォルダを一覧で確認し、コマンドを編集・削除できる。

## 管理者権限での実行

コマンドの編集画面で「管理者権限で実行」を有効にする。
起動時にWindowsのユーザーアカウント制御の確認が表示されたら、実行する場合は許可する。
確認をキャンセルすると、そのコマンドは起動しない。
